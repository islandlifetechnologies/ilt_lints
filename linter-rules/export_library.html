export_library

Stable Fix available #experimental #utility

Export all library source files from your package's exporter library file.

Details

DO export all library source files from your package's exporter library file.

Ensures all files matching any include glob (and not matching any optional exclude glob) for a configured exporter file are exported by that exporter. If a file overlaps include and exclude, exclude wins.

Examples

BAD: 
// lib/my_package.dart
// Missing export for `src/beta.dart`, which matches `src/**/*.dart`.
export 'src/alpha.dart';
GOOD: 
// lib/my_package.dart
// Exports all matching library files under `src/`.
export 'src/alpha.dart';
export 'src/beta.dart';

How to enable

To enable the export_library rule, add it to your analysis_options.yaml file:

analysis_options.yaml 
plugins:
  ilt_lints:
    version: ^2.0.0
    diagnostics:
      export_library: true

# Optional configuration (shown with defaults):
export_library:
  - exporter: lib/${packageName}.dart
    include:
      - src/**/*.dart
    exclude:
      - "**/g.dart"
      - "**/freezed.dart"
